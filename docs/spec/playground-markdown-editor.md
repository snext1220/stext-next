# Playground 本文エディターの入力補助仕様

## 状態

実装済み（2026-11-11）。

## 目的

Playground のシーン本文は Markdown で記述する。現在は複数行入力欄と本文マクロの挿入ボタンがあるが、よく使う Markdown の書式を覚えていない利用者には入力しづらく、選択した文字列へ書式を適用する操作もない。

本文を Markdown テキストとして直接編集する方式は維持したまま、よく使う記法をツールバーから挿入・適用できるようにする。

## 対象範囲

- Playground のシーン本文入力欄に、Markdown の入力補助を追加する。
- 次の記法をツールバーから扱えるようにする。
  - 見出し
  - 斜体
  - 箇条書き
  - 引用
  - リンク
- 既存の本文マクロ挿入ボタンは維持する。
- 本文は従来どおり Markdown 文字列としてシナリオに保存する。

## 動作仕様

- 本文欄のカーソル位置または選択範囲を基準に、ツールバー操作を適用する。
- 斜体は選択範囲を `*...*` で囲む。選択範囲がない場合は `**` を挿入し、カーソルを記号の間に置く。
- リンクは選択範囲をリンク文字列として `[選択文字列](URL)` にする。選択範囲がない場合は `[リンク文字列](URL)` を挿入し、リンク文字列の位置を選択する。URL は利用者が入力・編集する。
- 見出し、箇条書き、引用は、選択範囲があれば対象行の先頭にそれぞれ `# `、`- `、`> ` を付ける。選択範囲がなければカーソルのある行に適用する。
- 複数行を選択して箇条書きまたは引用を適用した場合は、選択した各行に記号を付ける。空行を含む場合も空行を含めて行単位で処理する。
- 見出しは選択範囲またはカーソルのある行に `# ` を付ける。見出しレベルの選択 UI は設けず、必要な場合は利用者が `#` の数を編集する。
- 編集後は本文欄へフォーカスを戻し、挿入・適用した箇所に応じたカーソルまたは選択範囲を設定する。
- 既存のマクロ挿入ツールバーのカーソル位置・選択範囲の扱いは維持する。
- 操作は React の本文変更通知を通してシナリオへ反映し、既存の自動保存と Undo/Redo の動作を利用する。

## 対象外

- WYSIWYG（見た目どおりに編集する）方式への変更。
- 本文のリアルタイムプレビュー。
- XML と Markdown の切り替え。
- 旧版 PgEditor の再現。
- 表、取り消し線、コードブロックなど今回列挙していない記法のツールバー対応。
- シナリオ本文の Markdown 解釈・描画・保存形式の変更。

## 互換性

- 既存シナリオの本文データ形式と既存の Markdown／マクロ記法は変更しない。
- ツールバー操作は通常の Markdown 文字列を挿入・編集するだけであり、未使用なら既存の編集・表示動作に影響しない。
- 既存のマクロ挿入機能、シーン本文の入力、保存、Undo/Redo を維持する。

## 完了条件

- 本文欄に、見出し・斜体・箇条書き・引用・リンクの入力補助がある。
- 選択範囲の有無と複数行選択に応じて、上記の動作仕様どおりに本文が編集される。
- 編集後に本文欄へフォーカスと適切な選択範囲が戻る。
- 既存の本文マクロ挿入とシーン本文の更新が引き続き動作する。
- 対象操作をテストで確認し、Playground の型検査と関連テストが通る。

## 実装規模の目安

既存の複数行入力欄とカーソル位置への挿入処理を拡張し、本文欄のテストを追加する。リアルタイムプレビューや WYSIWYG は含めず、**1〜2人日程度**を目安とする。
