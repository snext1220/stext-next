# 敵のいないシーンでのダイス表示仕様

## 状態

実装済み（2026-11-13）。

## 目的と背景

シーンの `dice` は表示・使用するダイスを指定するが、現在のプレイヤー画面と Playground 試遊では、敵がいないシーンに戦闘パネルを表示しない。そのため、敵のいないシーンでは `dice` を指定しても、画面上でダイスを振れない。

`begin` のシーン2200（渡河判定）と4500（休息後の兵力回復）は、敵が登場しない一方でダイス判定を求める。シナリオ本文の判定を変えずに、画面からダイスを振れるようにする。

## 対象範囲

- 敵がいないシーンで、シーンに `dice` が設定されている場合のダイス表示・振り直し。
- 共通の戦闘表示を使うプレイヤーと Playground 試遊の両方。
- `begin` のシーン2200・4500に、標準の6面ダイス2個を指定する。

## 動作仕様

- 敵がいないシーンでも `dice` が設定されていれば、ダイスと「ダイスを振る」操作を表示する。
- シーンに入ったときは、既存の `rollDice` と `dice` 設定に従って最初の目を表示する。振り直すと目だけを更新する。
- ダイスのみの表示では、敵カード、ダメージ倍率、敵への攻撃、戦利品など、敵との戦闘に関する操作は表示しない。
- 振った目はシーン内の表示に限り、セーブデータやキャラクターの状態を変更しない。選択肢の自動選択や、シナリオ本文に書かれた判定の自動処理も行わない。
- 敵がいるシーンの表示・操作、および敵がおらず `dice` も設定されていないシーンの表示は変更しない。敵がいるシーンでは、従来どおり `dice` 省略時に標準の6面ダイス2個を使う。
- Playground 試遊でもプレイヤーと同じ条件・表示・振り直し動作にする。

## 対象外

- ダイス目を使った選択肢の自動判定や、独自ルールの自動実行。
- ダイスの種類・個数の指定形式、スキーマ、乱数計算の変更。
- ダイス目をシーン移動・再読み込み・セーブをまたいで保存すること。
- シナリオ本文の判定内容や、判定後の手動ステータス更新方法の変更。

## 互換性と検証

- 既存の `dice` 指定と `rollDice` の計算結果を維持する。
- 敵がいるシーンでは従来の戦闘 UI が変わらないことを確認する。
- プレイヤーと Playground 試遊で、`dice` のある敵なしシーンではダイスと振り直しだけが表示され、`dice` のない敵なしシーンでは何も追加表示されないことを確認する。
- プレイヤーのテストで、振り直しがシーン内の目だけを更新し、主人公の状態を変えないことを確認する。
- `begin` のシーン2200・4500で、2個の6面ダイスを振れることと、シナリオ検査に通ることを確認する。
