# 「新・消えた王さまの杖」v2仕上げ仕様

## 状態

実装済み（2026-11-20）。確認事項は次のとおり決定した。

- editor 座標：自動レイアウトの保存のみ。
- 定型の戦闘指示：現状の文言を維持し、実画面とのずれの修正のみ行う（点検の結果、ずれはなく本文の変更なし）。
- 挿絵：現状維持。
- 一覧の題名：原本「王さま」に揃える。

## 目的と背景

[v2移行仕様](./scepter-v2-migration.md) に基づく移行は実装済みで、`validateScenario`／`checkScenario` はエラー・警告ともに0件、全253シーンの `summary`、8グループ、`meta.labels.free1`（瓶の生命力）、62シーンの挿絵が整っている。

一方、「終焉のゼロ - ドラゴンモード0 -」（`begin`）と「トラベラーズ☆イン」（`inn`）はその後の仕上げで、書庫の NT 勲章（`v2` フラグ）の付与、全シーンのフロー配置（`editor` 座標）の保存、［操作］パネル導入後の UI に合わせた操作案内の調整まで完了している。`scepter` の最終更新（2026-11-17）は［操作］パネル（2026-11-19）とダイスのフローティング化（2026-11-18）より前のため、同じ水準に仕上げる。

原本は [`scenarios/scepter/scenario.json`](../../scenarios/scepter/scenario.json)。旧 XML は参照用とし、再変換して上書きしない。物語・分岐・難易度は変えない。

## 対処すべき点

### 1. 書庫一覧（scenarios/index.json）の更新

- `scepter` のエントリーに `"v2": true` を追加する。書庫の NT 勲章表示と「NText対応」絞り込みの対象になる。
- `updated` を仕上げの完了日に更新する。
- 題名の表記ゆれを解消する。原本の `meta.title` は「新・消えた王**さま**の杖」、一覧は「新・消えた王**様**の杖」。原本の表記に合わせて一覧を修正する。
- `scenes`（253）、`results`（45）、`bgm` は現状と一致しており変更しない。

### 2. フロー配置（editor 座標）の保存

- `begin`・`inn` と同様に、全253シーンへ `editor` の x・y を設定して保存する。現状は0件で、Playground では毎回 dagre の自動配置で表示している。
- 自動レイアウト（[layout.ts](../../apps/playground/src/layout.ts)）を起点にし、8グループと物語のまとまり（本編の進行、チェックポイント再開の5シーン、バッドエンド群）が追いやすい配置に整える。
- シーン数が多いため、どこまで手調整するかは確認事項とする。本文・選択肢・遷移は変更しない。

### 3. ［操作］パネル導入後の本文確認

- 戦闘・ダイスのあるシーン（「敵の攻撃」案内35シーン、「ダイスを振る」案内32シーン前後）で、案内と実画面の表示・手順が一致することを確認する。ダイス・戦闘欄は［操作］タブへ移動済みのため、位置や手順を指す表現（「下の」など7シーンを含む）にずれがないか確かめる。
- 現在の「敵カードの『敵の攻撃』を押して〜」などの案内はボタン名として実在するため、全面的な書き換えはしない。ずれのある箇所だけを、現行画面に実在する名称で最小限修正する。
- `begin` の定型指示（`%red%`「操作」タブから、ダメージを反映させよ）に表記を寄せるかは確認事項とする。
- ダイスへの言及があるシーンはすべて `dice` または敵の設定があることを確認済みで、`dice` の追加は行わない。

### 4. 手動操作の残置箇所の再点検

- 移行仕様で手動と決めた箇所（2350 の休息と星の欠片、2110 の MP 上限振替、2500 の5回のダイス判定、3600・5170・6130・6140 のダイス結果、6160・6220、瓶の生命力の更新）は、エンジンの自動化機能に変更がないため手動のまま維持する。
- 各箇所の案内が「冒険者」パネルの「ステータスを編集」「記録」パネルの「経過シーン数」など現行の名称・手順と一致していることだけを確認し、推測で自動化しない。

### 5. 挿絵

- 既存の挿絵は62シーン・参照52点で、参照切れ・迷子のファイルはない（`intro.png` は書庫の代表画像で本文からは参照しない）。
- `begin`・`inn` の仕上げでは挿絵の追加・差し替えも行ったため、`scepter` でも追加するかは確認事項とする。既定では現状維持。

## 確認事項（承認時に決める）

| 項目 | 選択肢 |
| --- | --- |
| editor 座標 | 自動レイアウトの保存のみ／グループ・ルート単位の手調整まで行う |
| 定型の戦闘指示 | 現状の文言を維持（ずれの修正のみ）／`begin` 式「操作」タブ表記に揃える |
| 挿絵 | 現状維持／追加・差し替えの対象シーンを別途指定 |
| 一覧の題名 | 原本「王さま」に揃える（推奨）／原本側を「王様」に変える |

## 対象外

- 物語の改稿、ルート追加、難易度・報酬・結末・実績の調整。
- 瓶の生命力や2500の独自判定など、現行機能で表現できない処理の自動化。エンジン・スキーマの機能追加。
- チェックポイント再開の5シーン（11550、13000、13290、15000、16400）と番号入力の許可値、`meta.showSummary`、シーン・グループの BGM、戦闘ルールの変更。
- 既存セーブデータ（シナリオ ID キー）との互換性を損なう変更。

## 完了条件と確認方法

- `validateScenario`／`checkScenario` にエラー・警告がない。`npm test`（index.json のスキーマ検査を含む）が通る。
- 書庫一覧と詳細で `scepter` に NT 勲章が表示され、「NText対応」絞り込みに含まれる。題名が原本と一致する。
- Playground のフロー図で全シーンに保存済みの配置が使われ、グループと物語のまとまりを追える。
- ［操作］パネルを使う代表シーン（戦闘、敵なしダイスの14シーン、2500、2350、4000）で、本文の案内どおりに実画面で操作できる。固定ダイス等で効果の値・回数・タイミングを確認し、実施できない検証は未実施と報告する。
- 差分を原文と照合し、仕上げに不要な文章・難易度・結末の変更がない。
