# Playground 選択肢条件の入力候補拡充仕様

## 状態

実装済み（2026-11-13）。

## 目的

Playground の［シーン］タブでは、選択肢の表示条件をテキスト入力し、選択ボックスから条件の一部を差し込める。現在の候補は、条件パーサーとエンジンが扱う条件形式を網羅していないため、条件を選んで組み立てる操作だけで利用できない条件がある。

## 現状の不足

`packages/schema/src/condition.ts` の文字列パーサーと `packages/core/src/condition.ts` の評価処理に対し、現在の入力候補には次の不足がある。

- 実績（`r01:scenario-id`）、星（`s10`、`s1:0:0:...`）、経過シーン数（`e30`）の候補がない。
- 能力値は一部の固定例だけで、`free2`・`free3` と比較方法（以上・超過・未満・以下・一致）の例が揃っていない。
- パラメーターは数値一致の `:@0` だけで、以上や文字列一致の例がない。
- キャラクター条件には `xPOISON` しか状態異常の候補がなく、`FROZEN`・`STONE`・`CURSE`・`FORGET` が選べない。
- 未定義 ID をフラグまたはアイテムとして扱う互換形式（例：`q01`）の候補がない。

論理演算子、定義済みフラグ・アイテム、魔法、組み込み関数（`rand`・`include`・`range`・`cycle`）は既に選択できる。

## 対象範囲

- Playground の選択肢表示条件欄にある候補を、既存の文字列条件記法で拡充する。
- 実績・パラメーターはシナリオ定義から候補を作る。実績条件には現在の `meta.id` を使う。
- 星、経過シーン数、能力値、パラメーターの比較候補は、値を編集して使える代表的な条件式として用意する。
- 能力値候補は `hp`・`mp`・`str`・`int`・`dex`・`krm`・`free1`・`free2`・`free3` を対象にする。数値一致・以下は、既存記法で表せる同値の複合条件として候補に含める。
- キャラクター条件は現在の種族・性別・年齢に加え、エンジンで評価される状態異常の候補を選べるようにする。任意の職業など、固定一覧にない値は手入力で引き続き指定できる。
- 未定義 ID の互換形式は、用途が分かる代表例を候補に加える。
- 既存の入力欄、論理演算子、候補差し込み時の条件連結、直接編集、検証表示を維持する。

## 対象外

- 条件文字列の文法、条件 AST、スキーマ、エンジン評価処理の変更。
- 条件をフォームだけで編集する方式や AST 専用エディターの追加。
- 条件の入力補完、構文ハイライト、既存シナリオの一括変換。

## 互換性

候補を選ぶと従来どおり条件文字列を入力欄へ差し込む。シナリオ JSON の形式と既存の文字列条件は変更しない。利用者が入力欄を直接編集する操作も維持する。

## 完了条件

- 条件パーサーとエンジンが現在扱う各条件種別について、選択ボックスから代表的な条件式を差し込める。
- シナリオ定義に応じた実績・パラメーター候補が表示され、実績条件にシナリオ ID が含まれる。
- 不足していた星・経過シーン数・能力値・パラメーター比較・キャラクター状態の候補を確認できる。
- 候補を空の入力欄と既存条件の末尾に差し込んでも、従来の演算子連結と入力検証が動作する。
- 追加した候補の表示と差し込みをテストし、Playground の型検査と関連テストが通る。
