# 書庫のNT勲章アイコンの説明

## 状態

実装済み。

## 目的

書庫のNT勲章アイコンが何を意味するか、初めて見る人にも分かるようにする。

## 表示仕様

- 書庫冒頭の紹介文の直後に、NT勲章アイコンと「NT勲章は、NText向けに対応したシナリオの目印です。」という短い説明を表示する。画面幅が狭い場合も読めるようにする。
- 「NT勲章は、NText向けに対応したシナリオの目印です。」を初期状態では閉じた折り畳みパネルのタイトルとして表示する。開くと、「NT純正シナリオ」とはNText最新の仕様に沿って戦闘システムやパラメーターの自動更新などが調整されたシナリオであり、純正マークのないシナリオでもNTextは動作するが、一部のシーンに不自然な操作が混じる場合があることを説明する。
- 書庫一覧とシナリオ詳細のNT勲章に、同じ説明文をブラウザー標準のツールヒントとして設定する。マウスポインターを合わせると表示される。
- 一覧と詳細のアイコンには、既存の代替テキスト「NT純正シナリオ」を維持する。マウスを使わない人やタッチ操作の人も意味を確認できるよう、冒頭の説明は常時表示し、詳細はキーボードでも開閉できるようにする。
- 冒頭の説明用アイコンは説明文と重複して読み上げられないようにする。

## 対象外・互換性

- シナリオの判定条件や `scenarios/index.json` の `v2` フラグの意味は変えない。
- 検索、並び順、シナリオ詳細、セーブデータの動作は変えない。
- アイコンの図柄や各シナリオの対応状況は変更しない。

## 完了条件

- 書庫の冒頭にアイコンの説明が常時表示され、一覧と詳細の対象アイコンに同じツールヒントが設定される。
- 冒頭の折り畳みパネルは初期状態で閉じており、開くとNT純正シナリオの定義と、純正マークのないシナリオでもNTextは動作することを確認できる。
- `v2` が設定されていないシナリオには、これまでどおり個別のアイコンが表示されない。
- 一覧・詳細の代替テキストと既存の書庫操作が維持される。
- 関連する書庫テストで説明文、ツールヒント、対象の出し分けを確認する。
