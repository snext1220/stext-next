# プレイヤー画面の経過シーン数表示仕様

## 状態

実装済み。記録パネルの表示と、履歴件数と別に表示されることをテスト・型検査で確認済み。

## 目的と背景

エンジンはシーンへの移動回数を `GameState.ellapsed_scene` に保持し、条件判定にも使っているが、プレイヤー画面では確認できない。一方、「記録」パネルの「辿った節」の数字は「戻る」ための履歴件数であり、経過シーン数とは異なる。シナリオ本文が期限や経過数の確認を求める場合に、プレイヤーが正しい値を確認できるようにする。

## 対象範囲

- プレイヤーの「記録」パネルに、エンジンが保持する経過シーン数を表示する。
- 「辿った節」の履歴件数と混同しないよう、表示名を「経過シーン数」とする。
- [「新・消えた王さまの杖」の v2 移行](./scepter-v2-migration.md)では、この表示を使って Scene 2350 で基準値を確認し、Scene 4000 でグーランを離れてからの経過数を確かめる。50シーンの期限は変更しない。

## 表示仕様

- 経過シーン数は現在の `GameState.ellapsed_scene` の値をそのまま表示する。
- 「辿った節」の表示はこれまでどおり「戻る」履歴の件数とし、別々の表示として残す。
- 「戻る」操作では状態も履歴を戻すため、表示値もその時点の `ellapsed_scene` に戻る。セーブデータの読み込み後は、読み込んだ状態に保存されている値を表示する。
- エンジンのカウンター更新、条件判定、履歴の保存・上限・戻る動作は変更しない。

## 対象外

- 経過数の別カウンター追加や、戻る操作後も単調増加させる変更。
- Playground 試遊での表示。
- シナリオの期限や分岐、セーブデータ形式の変更。

## 完了条件と確認方法

- 「記録」パネルに「経過シーン数」と現在値が表示され、「辿った節」の件数とは別である。
- パネルの表示値が現在の `ellapsed_scene` と一致し、シーン移動・戻る・セーブデータ読み込みで現在状態に追従する。
- 「辿った節」の既存表示と戻る操作に変更がない。
- [プレイヤーマニュアル](../manual-player.md)に表示を追記する。
