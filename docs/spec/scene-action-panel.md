# シーン操作パネル仕様

## 状態

実装済み（2026-11-19）。戦闘またはダイスがある全シーンへの適用を含む。

## 目的と背景

[`inn` のシーン5100](../../scenarios/inn/scenario.json)では、ダイスを振り、本文のルールに従ってジョセフィーヌとの距離を数値欄で更新し、該当する出目なら［敵の攻撃］を押す。この繰り返しに必要な操作が本文と戦闘欄に分かれている。新しいパネルに操作を集め、一度ルールを読んだ後は、本文をスクロールせずに繰り返せるようにする。

## 対象範囲

- プレイヤーと Playground 試遊で、**敵がいるか、`dice` が設定されている全シーン**に［操作］を表示する。本文の数値入力の有無は表示条件にしない。敵ありで `dice` を省略した場合も、従来どおり標準のダイスを［操作］に表示する。
- 敵もダイス指定もないシーンでは［操作］を表示しない。別枠のルールだけが指定されている場合は、既存の折りたたみ表示を維持する。
- 対象のシーンでは、既存のダイス・戦闘欄と本文中の対象入力欄を［操作］タブへ**移動**する。本文側に同じ操作は残さない。入力欄の元の位置には［シーン操作で入力］のボタンを置き、［操作］を選んで対応する入力欄へ移動できるようにする。
- 移動する入力欄は、本文に表示されているシーン内数値メモ（`${input?0}` など）と名前付きゲームパラメーター（`${input?p01}` など）。選択肢の後の文章、別枠のルール、伏せ字の内側にある入力欄は、初期版では移動せず既存動作を維持する。

## タブと配置

専用の開閉ボタンは増やさず、プレイヤーの既存パネルの末尾に［操作］を追加する。

```text
［冒険者］［魔法］［持ち物］［記録］［操作］
```

| 画面 | 動作 |
| --- | --- |
| プレイヤー・広い画面 | 本文横の既存パネルに［操作］を追加。対象シーンでは［操作］を初期選択し、本文と操作を同時に表示する。専用の開閉はなく、他のタブと同じように切り替える |
| プレイヤー・狭い画面 | 既存の画面下メニューに［操作］を追加し、他の項目と同じ既存のシートに表示する。シーン進入時にシートは自動で開かない。本文に戻るときも既存の閉じ方を使い、読書位置を維持する |
| Playground 試遊 | 編集側のタブは増やさず、試遊内の［状態］への導線と並べて［操作］を用意する。試遊領域に幅があれば本文と並べ、狭ければプレイヤーに準じて本文のどこからでも切り替えられるようにする |

- 対象外のシーンでは［操作］を表示しない。対象シーンから移動して［操作］がなくなった場合、広い画面では従来の既定タブへ戻す。
- タブは常に一段。［操作］には短いラベルを使い、標準の文字サイズで幅320pxでも、タブを折り返さず横スクロールなしで表示する。文字拡大などで一段に収まらない場合は、タブ列だけを横スクロール可能にして、表示・操作できない項目を作らない。
- 切り替えだけでは本文のスクロール位置を変えない。本文の［シーン操作で入力］から移動する場合を除き、数値欄に自動でフォーカスせず、スマホのキーボードを出さない。
- 振り直し、数値入力、戦闘操作ではタブを切り替えない。画面幅変更やタブ切り替えで出目・入力値などを初期化しない。シーンの再入場、ロード、試遊の再開始などの初期化条件は既存動作に従う。
- 操作内容が収まらない場合はパネル内でスクロールする。敵一覧などをスクロールしても、ダイス操作帯はパネル内の上端に追従する。

## パネルにまとめる内容

5100で［操作］を選択した場合の概略。出目・合計・数値は例。

```text
シーン操作
出目  ⚃ ⚁   合計 6              ［ダイスを振る］
ダメージ倍率  ×1
シーン内メモ   ［−］［ 0 ］［＋］
ミミズ野郎   （敵の情報）        ［敵の攻撃］
```

| 内容 | 動作 |
| --- | --- |
| ダイス・倍率 | 個々の出目を既存の順番で表示し、合計と［ダイスを振る］を添える。敵がいるときは従来のダメージ倍率も表示する |
| 数値入力 | 対象欄がある場合のみ表示する。本文での出現順に並べ、直接入力と ±1 を用意する。名前付きの欄は従来のパラメーターに反映する。5100のような名前のない欄は［シーン内メモ］と表示し、複数ある場合は番号で区別する |
| 敵カード・戦闘操作 | 敵の表示と詳細、敵の攻撃、こちらからの攻撃、撃破チェックと戦利品を、既存欄と同じ表示条件・操作条件で提供する。処理は一回分だけ行い、結果通知はパネルを開いたまま確認できる。敵がいなければこの欄は表示しない |
| 別枠のルール | シナリオに既存の別枠ルールが指定されている場合は、既存の折りたたみ表示ごとパネルに移す |

- **物語本文と選択肢は従来の場所に残す。** 5100のように本文に書かれたルールは移さない。PCでは横の本文で読み、スマホでは既存シートから元の箇所に戻って見直す。原文のピン留め・要約、距離の増減や遭遇・分岐の自動判定は対象外。既存の冒険者・魔法・持ち物・記録の内容やセーブ操作は変更しない。

## 互換性と完了条件

- シナリオ JSON、セーブ形式、ダイスや戦闘の計算を変えない。開閉だけで出目、入力値、敵HP、倍率、撃破チェック、戦利品の取得状態を初期化しない。数値メモは従来どおりシーン内に限り、名前付きパラメーターの保存・ロードは既存仕様を維持する。
- 両アプリの幅390px・1280pxのブラウザーで、5100のルールを読んだ位置から［操作］を使い、本文をスクロールせずに振り直し・距離入力・敵の攻撃を複数回行える。スマホではシートを閉じると同じ読書位置を確認できる。
- 両アプリで、数値入力がなくても、敵あり・`dice` 省略ならダイスと戦闘欄が、敵なし・`dice` 指定ありならダイスだけが［操作］に表示される。どちらも本文の前後にダイス操作帯や戦闘欄を置かない。敵もダイス指定もないときは、数値入力や別枠のルールがあっても［操作］を追加しない。
- 対象シーンにダイス・数値入力・戦闘操作の重複がなく、元の入力位置から該当欄を開けることを確認する。攻撃の処理と通知は一回分だけ行われる。複数の数値メモが別々の値を保ち、別シーンへ持ち越されないことも確認する。
- 対象外のシーンに［操作］が出ないこと、幅320px（標準の文字サイズ）で全タブが一段に収まること、拡大時にもページ全体に横スクロールを生じさせず、キーボードで全項目に移動できることを確認する。
