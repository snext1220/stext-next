# プレイヤーの魔法・ボーナス効果表示仕様

## 状態

実装済み。パソコン・スマートフォン幅とキーボードで表示・開閉を確認した。タッチ実機での確認は未実施。

## 目的と範囲

プレイヤーが、魔法や適用中のボーナスアイテムの効果について、自動で反映される部分と自分で扱う部分を画面上で判断できるようにする。既存の［魔法］と［冒険者］を簡潔に保ち、詳しい説明は開いて確認できるようにする。

対象はプレイヤーの［魔法］と［冒険者］のボーナス表示、および[プレイヤーマニュアル](../manual-player.md)。ゲームの自動化、魔法や戦闘のルール、シナリオやセーブデータの形式は変更しない。Playground 試遊は対象外。

## 画面表示

### 表示の意味

各魔法と適用中のボーナスに、文字で次のいずれかを表示する。色やアイコンだけに依存しない。

| 表示 | 意味 |
| --- | --- |
| 自動 | 効果が使用時や開始時など所定のタイミングで反映される。手動で扱う効果や使用条件がある場合は詳細に記載する |
| 手動 | 記載された効果は自動反映されず、プレイヤーが扱う |

「自動」はプレイヤーの操作が不要という意味ではない。魔法は［唱える］、戦闘は攻撃を受ける操作など、既存の操作が必要である。魔法の「手動」は**効果**についての表示であり、［唱える］を押すと必要な星は自動消費される。

### 魔法

- すべての魔法に分類を表示する。唱えられない魔法にも表示し、必要な星の表示やボタンの条件は変えない。
- 分類の意味はパネル上部の折りたたみ説明で確認できる。追加の補足は常時表示しない。
- ［手動］の魔法と RESURRECT は、その概要を押して個別の操作説明を開閉する。その他の［自動］の魔法には開閉操作を付けない。必要な星が足りない場合も説明を開け、開閉では［唱える］を実行しない。
- 個々の魔法の説明・分類は、次の実際の処理に合わせる。

| 分類 | 魔法 | 表示・説明の要点 |
| --- | --- | --- |
| 自動 | HEAL、PEACE | HP・MP回復は最大値まで |
| 自動 | CURE、MELT、STONE-FLESH、UN-CURCE、AIR-HAND | 対応する状態異常を解除 |
| 自動 | REDUCE-LIFE | HPを25減らし、状態異常を解除 |
| 自動 | RESURRECT | HP・MPをそれぞれ最大値の半分（端数切り捨て）に**設定**。冒険中１回の制限は自分で管理。現在値より下がる場合もある |
| 手動 | PROTECT、HOLY-WATER | 対応するダメージを受けるとき［操作］の倍率を1/2にし、効果終了後は戻す。１ターンの管理は手動 |
| 手動 | REJUVENATE | 判定のやり直しを自分で扱う。結果の自動取り消しはない |
| 手動 | CHANGE-AIR | 戦闘回避と戦利品を得ない扱いを自分で判断する |
| 手動 | GIVE-VIGOR | 敵の攻撃力２倍と戦利品２倍を自分で扱う。戦利品の倍増は自動ではない |
| 手動 | EXPLOSION、DELUGE、FREEZE、DESTROY-A、LIGHT-CROSS、NOILA-TEM | 対象の敵の全滅は自動反映されない。撃破チェックは目印であり、敵HPや戦利品を変えない |

効果を手動で扱う際に、既存画面でできないことを可能であるかのようには案内しない。特に戦利品の倍増や判定結果の取り消しを自動操作として説明しない。

### ボーナスアイテム

- ［冒険者］には従来どおり適用中のボーナス１個と効果を表示し、その分類を添える。未所持・未適用の一覧は追加しない。
- ボーナス名は見出しの横に表示し、概要と展開時の詳細は欄の全幅に表示して改行を抑える。概要は右寄せ、展開時の詳細テキストは左寄せとする。
- 自動部分と手動部分がある場合も［自動］と表示する。個別の詳細があるボーナスは概要を押して開閉し、詳細がないボーナスには開閉操作を付けない。追加の補足や一般説明は表示しない。
- 新しい冒険では所持ボーナスから１個がランダムに選ばれ、その効果が適用されることをマニュアルで説明する。開始時の星・能力値・状態異常とシーン進入時の効果は、それぞれのタイミングで反映される。
- 未知のボーナスIDは従来どおりIDを表示し、自動・手動を推測せず「効果未確認」と表示する。

| 分類 | 対象 | 表示・説明の要点 |
| --- | --- | --- |
| 自動 | 金の卵、ガラティーン、五元素のマント、アマゾンの剣、幸福のコイン、ムラサメブレード、G・スレイヤー、D・スレイヤー | 開始時に対応する星を加算 |
| 自動 | ブルーリボン、王家のダイヤモンド | 開始時にSTRまたはINTを１加算 |
| 自動 | 水晶の剣、王様の杖、塩酸、紅玉 | シーン進入時に記載の確率でHP・MPを変化 |
| 自動 | 中和剤、聖水、チルドの実、銀のハーモニカ、真実の鏡 | 対応する状態異常を防ぐ |
| 自動 | 鏡の盾、銀の竪琴 | 戦闘の攻撃を受ける操作で、それぞれHP・MPダメージを１軽減 |
| 手動 | 不老長寿の水、タリスマン | ［ステータスを編集］で回復を反映し、冒険中１回の使用を自分で管理 |
| 手動 | パンドラの箱、魔法の絨毯 | ダイス条件、戦闘回避、戦利品の扱いを自分で判断 |
| 自動 | 血まみれの斧 | 開始時の呪いは自動。解除後の星を消費しない攻撃魔法と３回の制限は自動対応していない。［唱える］には必要な星が必要で、通常どおり消費する |
| 自動 | トリカブト | 開始時の毒は自動。解除までの魔法ダメージ半減は［操作］で倍率を調整し、効果終了後に戻す |
| 自動 | ギャルのパンティー | 開始時の忘却は自動。解除時の能力値回復は［ステータスを編集］で反映する |

### コンパクトさと操作性

- 既存の効果説明と分類を常時表示する。魔法とボーナスは個々の概要から詳細を開く。
- パソコン・スマートフォンの両方で、タッチとキーボードから説明を開閉できる。ホバー専用の説明にしない。
- 狭い画面や文字拡大時も文字・ボタンが重ならず、パネル内で内容を確認できる。

## マニュアル

[プレイヤーマニュアル](../manual-player.md)の冒険者パネル・戦闘に関連する箇所に、分類の意味、上記の効果一覧、必要な手動操作と未対応事項を追記する。

［魔法］からの詠唱と、シナリオの選択肢に指定された魔法も区別する。後者は星を消費し、結果は遷移先のシーンに設定された効果に依存する。通常のシナリオ内アイテムはボーナスアイテムとは別であり、［持ち物］の［使う］から設定された効果と消費が反映されることも説明する。

## 保留事項

次の自動化・操作支援は検討候補であり、現時点では実装しない。

- ギャルのパンティー：忘却解除時の能力値回復。対象となる能力値と解除経路を確認する。
- 不老長寿の水・タリスマン：使用ボタンによる回復。回復量の解釈と、冒険中１回の使用管理・既存セーブの扱いを検討する。
- トリカブト：毒の間の魔法ダメージ半減。対象の判定範囲と手動倍率との重複を検討する。
- PROTECT・HOLY-WATER：戦闘倍率の設定支援。１ターンの終了をどのように扱うか検討する。
- 敵の全滅魔法・戦闘回避：敵HP、戦利品、シナリオ固有ルールへの影響を確認する。

## 完了条件

- 魔法20種と既知のボーナス28種について、上記の分類と効果が実際の処理に一致する。分類の更新漏れを検出できるようにする。
- 魔法の詠唱条件・星消費、能力値や状態異常の更新、戦闘・ボーナスの処理、既存データの読み書きが変わらない。
- 自動・手動の代表例、手動の条件を含む自動の効果、未知のボーナス、説明の開閉をテストする。魔法の使用や適用ボーナスの既存表示も維持する。
- パソコン・スマートフォン幅で、表示の重なりがなく、説明をキーボードとタッチで開閉できることを確認する。
- マニュアルの説明と画面の分類が一致し、未対応の操作を自動化済みと説明しない。
