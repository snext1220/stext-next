# 「序：黒船来航」v2移行の追加対応仕様

## 状態

実装済み（文言整理）。別途検討していた影響箇所も、現在の状態・運用で問題ないことを確認済み。

## 目的

`baku01` の本文に残る旧プレイヤーの画面名・操作名を、現行プレイヤーの表示に合わせる。旧シナリオの物語、判定、戦闘、分岐、効果は変更しない。

旧XMLは参照用とし、[`scenarios/baku01/scenario.json`](../../scenarios/baku01/scenario.json) を原本として直接編集する。旧リポジトリのファイルは変更しない。

## 対象範囲

### 今回の文言整理

現行画面で同等の操作ができる箇所に限り、シナリオ本文とルールシーンの操作案内を現行UIの表示名に置き換える。

| 旧表記 | 現行表示に合わせた案内 |
|---|---|
| `Battle Sheet` | ［操作］ |
| ダイスをクリック | ［ダイスを振る］を押す |
| HP欄をクリック（冒険者の攻撃） | 対象の［攻撃する］を押す |
| ダメージ欄・ダメージ式をクリック（敵の攻撃） | 対象の［敵の攻撃］を押す |
| `Status Sheet` | ［冒険者］ |
| `Items Sheet` | ［持ち物］ |
| `Magic Sheet` | ［魔法］ |
| `Free1` | 表示名の［武器耐久度］ |

現在の敵カードで実際に操作できる敵・ボタンだけを案内し、対象、回数、順序、条件、手動で選ぶ成功・失敗分岐を維持する。［操作］はシーンに敵または `dice` がある場合に表示されるため、表示されないシーンでパネルがあるかのような案内に置き換えない。

## 実施結果

- 文言整理時に、現行UIに対応する画面名・操作名をシナリオ本文とルールシーンで置き換えた。当時、操作パネルが表示されなかった5シーンには `Battle Sheet` を残していたが、その後、操作パネルの設定と案内が更新された。
- シーン3130の［追加ダメージ］は文言整理時に変更せず、シーン1650の戦利品操作名は［戦利品：アポピス］に合わせた。これらの現在の運用は後述のとおり確認済み。

### 変更しないもの

- 選択肢、遷移、条件、敵データ、シーン効果、実績、数値、シーンID、本文の物語上の結果。
- 文章に記載されたダイス判定・独自ルールの自動化。現行のダイス操作は出目を表示するもので、本文の条件判定や選択肢の制御はしない。
- ［戦利品］を再使用可能にする共通UI・エンジンの変更。
- ［操作］がないシーンの判定・ダメージを、根拠なく別の操作や効果に置き換えること。

## 影響箇所の確認結果

文言整理後に残っていた以下の事項は、現在の状態・運用で問題ないことを確認した。

- **ダイス・ダメージ操作**：シーン274、2500、2520、2740には標準ダイスが設定され、シーン2560には瘴気の敵が設定されている。
- **アポピスへの反復操作**：シーン1650では、戦利品の再取得に一度甲板へ戻る手順を案内している。再訪時の武器耐久度の減少とHP・MPの回復を含め、現在の運用で問題ない。
- **追加ダメージ**：シーン3130の現在の内容・運用で問題ない。
- **Free2の表示名**：現在の「？？？」の表示で問題ない。
- **本文判定の手動運用**：プレイヤーが出目や能力値を本文の条件と照らし合わせ、必要な回数を集計して成功・失敗の選択肢を選ぶ運用で問題ない。現行の判定や選択肢の制御は自動化されていない。

## 互換性と完了条件

- 対象の編集はシーン本文・ルール本文の操作案内に限定し、選択肢、効果、条件、敵、シーン数、セーブ形式に差分を作らない。
- 現行UIにない操作や、自動判定されないルールを、利用可能または自動化済みであるかのように書かない。
- 変更後に旧画面名・旧ボタン名の残存箇所を検索し、残す箇所は本仕様の対象外として説明できるようにする。
- `validateScenario` と `checkScenario` を実行する。本文の文言差分を確認し、移行に不要な変更を含めない。
- 実プレイヤーで、敵ありの戦闘操作、ダイス判定、冒険者・持ち物・魔法パネルの案内が現行UIと一致することを確認する。未実施の確認は報告する。
