# 「序：黒船来航」v2移行の追加対応仕様

## 状態

実装済み（文言整理）。

## 目的

`baku01` の本文に残る旧プレイヤーの画面名・操作名を、現行プレイヤーの表示に合わせる。旧シナリオの物語、判定、戦闘、分岐、効果は変更しない。

旧XMLは参照用とし、[`scenarios/baku01/scenario.json`](../../scenarios/baku01/scenario.json) を原本として直接編集する。旧リポジトリのファイルは変更しない。

## 対象範囲

### 今回の文言整理

現行画面で同等の操作ができる箇所に限り、シナリオ本文とルールシーンの操作案内を現行UIの表示名に置き換える。

| 旧表記 | 現行表示に合わせた案内 |
|---|---|
| `Battle Sheet` | ［操作］ |
| ダイスをクリック | ［ダイスを振る］を押す |
| HP欄をクリック（冒険者の攻撃） | 対象の［攻撃する］を押す |
| ダメージ欄・ダメージ式をクリック（敵の攻撃） | 対象の［敵の攻撃］を押す |
| `Status Sheet` | ［冒険者］ |
| `Items Sheet` | ［持ち物］ |
| `Magic Sheet` | ［魔法］ |
| `Free1` | 表示名の［武器耐久度］ |

現在の敵カードで実際に操作できる敵・ボタンだけを案内し、対象、回数、順序、条件、手動で選ぶ成功・失敗分岐を維持する。［操作］はシーンに敵または `dice` がある場合に表示されるため、表示されないシーンでパネルがあるかのような案内に置き換えない。

## 実施結果

- 現行UIに対応する画面名・操作名をシナリオ本文とルールシーンで置き換えた。`Battle Sheet` は操作パネルが表示されない5シーン（274、2500、2520、2560、2740）に残している。2500の `Magic Sheet` は、操作パネルとは独立して使える［魔法］に置き換えた。
- シーン3130の［追加ダメージ］は、現行UIに同名の操作がなく、［敵の攻撃］で代替できるか確認できていないため残した。
- シーン1650の戦利品操作名は［戦利品：アポピス］に合わせた。複数回取得できない制約や再訪時の副作用は変更していない。

### 変更しないもの

- 選択肢、遷移、条件、敵データ、シーン効果、実績、数値、シーンID、本文の物語上の結果。
- 文章に記載されたダイス判定・独自ルールの自動化。現行のダイス操作は出目を表示するもので、本文の条件判定や選択肢の制御はしない。
- ［戦利品］を再使用可能にする共通UI・エンジンの変更。
- ［操作］がないシーンの判定・ダメージを、根拠なく別の操作や効果に置き換えること。

## 別途検討する影響箇所

今回の文言整理では解決せず、対応方法の決定後に別作業として扱う。

### ダイス・ダメージ操作ができないシーン

現行のシーン操作パネルは、敵がいるかシーンに `dice` が設定されている場合に表示される。`baku01` の次のシーンには敵も `dice` もないが、本文では操作を求めている。

| シーン | 現状 |
|---|---|
| 274 | ゾロ目判定を求めるが、ダイス操作が表示されない |
| 2500 | INTに応じたダイス判定を求めるが、ダイス操作が表示されない |
| 2520 | 10回のダイス判定を求めるが、ダイス操作が表示されない |
| 2740 | 連続したダイス判定を求めるが、ダイス操作が表示されない |
| 2560 | ダメージ反映を求めるが、敵・ダイス操作がなく、ダメージ量や適用対象も定まっていない |

これらのシーンでは、存在しない［操作］パネルを案内しないため、本文の `Battle Sheet` を今回の文言整理では置き換えていない。

274、2500、2520、2740に標準ダイスを設定すれば操作を表示できるが、設定追加の承認を得てから行う。2560は必要なダメージ処理が特定できないため、自動化や数値の追加を推測で行わず、作者確認を要する。

### アポピスの耐久値を複数回減らす操作

シーン1650の敵 `m17` は `free2/-4/アポピス` を戦利品として持ち、`free2` がアポピスの耐久値を表す。現在のUIでは戦利品は敵ごとにシーン滞在中1回だけ取得できるため、本文が認める複数回のダメージを同じ訪問中に適用できない。

1650から1800へ戻り、1800から1650を選び直す方法では、戦利品の取得状態は初期化され、`free2` の値は維持される。一方、再訪のたびに1650の武器耐久度が3〜5減り、1800ではHP・MPが各3回復する。別案としてステータス編集でFree2を手動変更できるが、通常の戦闘操作ではなく、Free2の表示名も「？？？」である。

対応案として、現在の再訪経路を正式な手順として扱う、Free2の手動編集を案内する、戦利品とは別の反復可能な敵操作を設ける、のいずれを採るかを決める。シーン遷移や共通UIの変更は、この仕様の承認だけでは着手しない。

### 追加ダメージの操作

シーン3130には、聖水の効果時間を超えた後に［追加ダメージ］からダメージを反映する案内がある。現行の敵カードに同名の操作はなく、［敵の攻撃］で代替できるかも確認できていないため、今回の文言整理では変更していない。追加ダメージの対象・計算・適用方法を確認してから別途扱う。

### Free2の表示名

Free2はアポピスの耐久値であることが確認されているが、現在の表示名は「？？？」で、本文には内部名 `Free2` が残っている。表示名を「アポピス耐久値」などに変更するかは、画面上の表示や既存セーブへの見え方を確認して別途決定する。今回の旧画面名整理では表示名を変更しない。

### 本文判定の手動運用

INT・出目の条件、複数回の集計、成功・失敗後の選択は、現行UIでは自動判定されない。これらを自動化する場合は、本文に書かれたルールを個別にモデル化する必要がある。対象範囲、判定結果の適用方法、既存ルートへの影響を別途仕様化し、単なる画面名置換と混在させない。

## 互換性と完了条件

- 対象の編集はシーン本文・ルール本文の操作案内に限定し、選択肢、効果、条件、敵、シーン数、セーブ形式に差分を作らない。
- 現行UIにない操作や、自動判定されないルールを、利用可能または自動化済みであるかのように書かない。
- 変更後に旧画面名・旧ボタン名の残存箇所を検索し、残す箇所は本仕様の対象外として説明できるようにする。
- `validateScenario` と `checkScenario` を実行する。本文の文言差分を確認し、移行に不要な変更を含めない。
- 実プレイヤーで、敵ありの戦闘操作、ダイス判定、冒険者・持ち物・魔法パネルの案内が現行UIと一致することを確認する。未実施の確認は報告する。
