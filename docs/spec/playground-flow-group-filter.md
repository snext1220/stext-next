## 目的・背景

大きなシナリオで、編集したい章や場面のまとまりだけをフロー図に表示し、シーンや接続を見つけやすくする。

現在は、フロー図上部にグループ別のシーン選択ボックスがある。グループは「最初のシーンID」昇順、各グループ内はシーンID昇順で並び、未所属のシーンは末尾にまとめる。シーンを選ぶと編集対象と表示位置が切り替わるが、フロー図自体は全シーンを対象としている。

本案は、この選択ボックスを維持したまま、フロー図の表示範囲を切り替える操作を追加するものとする。当初対象外としていた「範囲を絞った表示」を将来追加する案であり、現行の提供機能は変更しない。

## 対象範囲

- 一つのグループ、またはグループ未所属のシーンによるフロー図の絞り込み。
- 表示ノード・線・ミニマップ・件数表示の連動。
- 既存のシーン選択、検査結果からの移動、編集、試遊との整合。
- グループやシーンの編集、Undo/Redo、作品切り替え時の表示状態の整理。

## 動作仕様案

### 操作欄とシーン一覧

フロー図上部に［表示グループ］を追加し、既存の［編集するシーン］と並べる。狭い画面では折り返し、横にはみ出さないようにする。

```text
［表示グループ：すべて ▼］［編集するシーン：0：プロローグ ▼］
```

- ［表示グループ］は「すべて」「定義済みの各グループ」「グループ未所属」の順とする。
- グループの並びは「最初のシーンID」昇順とし、同じ開始IDでは定義順を保つ。同名でも別定義として扱い、選択肢に範囲を併記する。
- 初期表示は「すべて」。グループがない場合も全シーンを表示できる。
- 空のグループや未所属のシーンが0件の場合も項目を残し、件数を併記する。
- **既存の［編集するシーン］は絞り込まず、全シーンをグループ別に選べる状態を維持する。** 一覧から範囲外へ直接移動できるようにする。
- フロー図上部に「表示 N / 全 M シーン」と現在の表示グループを示す。「すべて」に戻す操作で絞り込みを解除できる。

この案では選択ボックスが2個になるが、役割は「フロー図の表示範囲」と「編集対象の選択」で分ける。以前検討した、グループによってシーン一覧の候補を絞る2段選択とは異なる。

### グループ所属の判定

- 既存の `groups[].start`・`end` を使い、シーンIDを数値として比較する。両端を含む。
- 数値で比較できないシーンIDはグループ未所属とする。
- 新しいグループIDや所属データは追加しない。`editor.group` は判定に使わない。
- グループ未所属は、有効な範囲のどのグループにも入らないシーンとする。
- 編集途中の範囲の空欄・非数値・逆転は無効とし、そのグループではノードを表示せず、理由を表示する。空欄を数値の0として扱わない。
- 重複範囲は既存の検査方針に従う。下書きに重複があっても表示処理は停止せず、選択した範囲内のシーンを表示する。この機能のために重複を許可する仕様へ変更しない。
- 所属判定はシーン一覧と整合させる。入力途中の値の扱いに差がある場合は、実装前に共通の判定規則と影響範囲を確認する。

### ノード・線・表示位置

- 選択グループに所属するシーンだけを表示する。「すべて」では現行どおり全シーンを表示する。
- 接続線は、移動元と移動先の両方が表示対象の場合だけ表示する。ランダム分岐や入力分岐も、各移動先について個別に判定する。
- ミニマップも表示対象のノードだけにする。
- グループ切り替え時は、保存済みの座標を維持して、表示対象が収まるように表示位置と倍率を調整する。最大倍率は現行どおり1倍とする。
- 「すべて」に戻した場合は、現行の初期表示と同じく、大きなシナリオでは最初のシーン付近を読みやすい大きさで表示する。
- 表示対象が0件の場合は「このグループに表示できるシーンはありません」と解除操作を表示する。存在しないノードを対象に表示位置の調整を実行しない。
- 絞り込み操作だけでは、シーンの座標や本文、選択肢を変更しない。

### グループ外への接続

- グループ外への接続は削除せず、図上の線だけを非表示にする。
- 絞り込み中は「範囲外への接続 X 本／範囲外からの接続 Y 本」を表示する。表示対象と非対象をまたぐ、実在シーン間の有向接続を各1本として数える。複数移動先は個別に数える。
- 存在しない移動先は外部接続の件数に含めず、既存の検査で扱う。
- 編集欄の選択肢は範囲外へのものも含めてすべて表示する。
- 外部接続先の仮ノード、境界上の線、外部接続一覧は初期対象に含めない。

### 編集対象・検査・試遊との関係

| 操作・変化 | 表示範囲と選択の扱い |
| --- | --- |
| グループを切り替える | 編集対象と編集欄は維持する。対象が範囲外なら「編集中のシーンは表示範囲外です」と表示する |
| 範囲内のシーンを一覧・検査結果から選ぶ | 絞り込みを維持し、対象へ移動する |
| 範囲外のシーンを一覧・検査結果から選ぶ | 「すべて」に戻して対象へ移動する。解除したことを通知する |
| シーンを追加する | 追加結果を編集対象とし、範囲外なら絞り込みを解除して対象へ移動する。採番規則は変えない |
| シーンIDの変更で編集中のシーンが範囲外になる | 絞り込みを解除して、変更後のシーンへ移動する |
| シーンを削除する | 既存の編集対象切り替え規則に従い、表示対象を再計算する。自動的に別グループへ切り替えない |
| グループの追加・削除・並べ替え、名前・範囲の変更 | 古い選択が別の定義にすり替わらないよう、「すべて」に戻し、その旨を通知する。編集対象は維持する。BGM・戦闘ルールだけの変更では解除しない |
| Undo/Redo | 表示対象を再計算する。グループの数・順序・名前・範囲が変わった場合は「すべて」に戻す。シーンだけの変更では絞り込みを維持し、編集対象が範囲外になった場合はその旨を表示する |
| 試遊で範囲外のシーンに進む | 試遊は制限しない。絞り込みは維持し、現在の試遊シーンが範囲外であることと、絞り込みを解除して表示する操作を示す |

範囲外のシーンを編集しているだけで自動解除し続ける実装にはしない。利用者が明示的にグループを切り替えた場合と、シーンへ移動する操作を区別する。

試遊のシーン表示・ハイライトと編集対象の選択は引き続き別状態とし、表示範囲の変更で試遊を再開始したり、シーンの効果を再適用したりしない。

### 自動配置・編集・保存

- 絞り込み中の［自動で並べる］は無効にし、「すべてのシーンを表示してから実行してください」と案内する。見えないシーンを意図せず再配置することを避ける。
- 表示中のシーンは従来どおりドラッグして座標を保存できる。線を引く操作は表示中のノード間で行い、既存の選択肢追加処理を使う。
- 表示専用のノード・線を抽出するだけにとどめ、絞ったシナリオを編集・保存処理へ渡さない。
- 自動保存、JSON・ZIP出力、素材管理、検査、試遊は常にシナリオ全体を対象とする。
- 絞り込みは一時的な画面状態であり、作品データやUndo/Redo履歴に含めない。ブラウザ再読み込み、プロジェクト切り替え、新規作成、読み込み時は「すべて」に戻す。

## 対象外

- 複数グループの同時選択。
- 任意のID範囲、検索語、条件式による絞り込み。
- グループの階層化、自由なシーン所属指定、新しいグループIDの導入。
- 表示中のシーンだけの保存・書き出し・検査・試遊・自動配置。
- フィルター設定やグループ別の表示位置の永続保存。
- BGMや戦闘ルールのグループ判定・実行動作の変更。
- 旧版のフィルターUI全体の再現。

## 互換性・移行への影響

- シナリオ形式・JSON Schema・既存作品のグループ定義は変更せず、データ移行を不要とする。
- 既定値「すべて」では現行の全シーン表示と編集操作を維持する。
- 編集途中の不正な範囲は理由を表示し、勝手に「すべて」や別グループへ読み替えない。
- 現行マニュアルやヘルプは、現時点では未実装の説明を維持する。実装後に、提供機能に合わせて更新する。

## 完了条件・確認方法（将来の実装時）

1. グループの開始ID順、同じ開始ID、同名グループ、所属範囲の両端、数値ID・文字列ID、未所属、空グループを確認する。
2. 無効な範囲・重複範囲を含む下書きでも、通知を伴って編集を続けられる。
3. 内部接続だけが図に表示され、通常・ランダム・番号入力・文字入力の外部接続件数が正しい。
4. ノード・線・ミニマップ・件数が同じ表示範囲に連動する。切り替えと0件表示で表示位置が破綻しない。
5. 一覧・検査からの移動、追加・ID変更・削除、グループ編集、Undo/Redo、作品切り替えで上表どおりに動く。
6. 範囲外への試遊進行と、戦闘を含む試遊状態を維持する。
7. 表示切り替え前後で作品データが変わらず、保存・出力に非表示のシーンや選択肢も含まれる。検査結果も変わらない。
8. 絞り込み中は全体の自動配置を実行できない。ドラッグ編集は対象シーン以外の座標を変更しない。
9. Safariの画面外描画省略、狭い画面、キーボード操作、既存のシーン選択の表示位置移動を確認する。
10. 所属・表示対象・接続抽出の単体テスト、画面の統合テスト、実ブラウザ確認を行い、対象の型検査・Lint・ビルドを通す。

## 実装範囲と規模の目安

主な変更候補は `apps/playground/src/` の `App.tsx`（表示状態・操作欄）、`FlowView.tsx`（表示対象・ミニマップ・表示位置）、`model.ts`（所属・接続抽出）、関連するスタイルとテスト。現行の全体データを扱う保存・試遊経路は維持する。

単一グループの絞り込みと上記の連動・回帰確認・文書更新を含め、**2〜4人日程度**を目安とする。既存のシーン一覧は実装済みであり、この見積もりは追加の絞り込み機能だけを対象とする。複数グループ選択や外部接続先の図示は含めない。

## 着手前の確認事項

以下は本書の推奨案であり、ユーザー承認前の決定事項ではない。

- ［表示グループ］を別に設け、既存のシーン一覧は全件表示のまま維持する。
- 初期段階は単一グループだけに絞り、外部接続は件数で知らせる。
- 範囲外への明示的な移動では解除し、単なるグループ切り替えでは編集対象を維持する。
- 絞り込み中の自動配置は無効とし、フィルター状態は保存しない。
