# サイト紹介バナーの配置仕様

## 状態

実装済み（2026-11-11）。

## 目的

作成した紹介イラストとサイトリンクバナーを、内容に合う案内ページへ配置する。シナリオ募集バナーは今回の対象外とする。

## 対象範囲

- 「ソーサリアン Text とは？」ページに、紹介用イメージイラストと「NextからText、そしてNTextへ…」バナーを配置する。
- 「関連リンク」ページに、「遊ぶ。創る。無限の冒険譚へ。」バナーを配置する。
- 「関連リンク」ページの「起源（オリジン）、そして更なる展開（ステージ）へ」に、旧ページにあったNext企画とブログのバナーを追加し、Next、Text、Next 2020、NTextの流れを説明する。
- 既存の説明、リンク、ページ構成は維持し、画像に適切な代替テキストを付ける。
- 紹介イラストは、NTextロゴを合成した `assets/site/banner/top.png` を原本として `assets/site/ntext-promo.webp` に変換する。PNG原本は変更せず、配信用WebPは表示品質を保って最適化する。

## 配置・表示仕様

- 紹介用イメージイラストは、「ソーサリアン Text とは？」ページのタイトル・リード文の直後、最初の説明文の前に配置する。本文幅に合わせて縮小し、画面幅に応じて表示幅を調整する。クリック時は既存の `ImagePreview` で拡大表示できるようにする。
- 「NextからText、そしてNTextへ…」バナー（660×80）は、同ページの「ソーサリアン Text から NText へ」の説明直後に配置する。
- 「遊ぶ。創る。無限の冒険譚へ。」バナー（660×80）は、「関連リンク」ページの「起源（オリジン）、そして更なる展開（ステージ）へ」節の紹介文と既存リンクの後に配置する。
- 紹介バナーと歴史バナーは既存の `ImagePreview` を使い、画像自体を拡大表示できるようにする。ページ遷移を伴うリンクにはしない。
- 「SORCERIAN Next」バナーと「新時代のソーサリアンを提案する」ブログバナーを、Next企画およびブログの外部リンク付きで、同節に追加する。参考ページと同じ画像URLを使い、NextバナーはSORCERIAN Next、ブログバナーは該当ブログへリンクする。
- 同節に年代順が分かる説明を加える。2013年のNext企画とその起源となったiOS版シナリオコンテスト、2017年開始のText、2020～21年のSORCERIAN Next 2020、Textの作品とセーブデータを引き継ぐNTextを紹介し、Next 2020とNTextが別の展開であることを誤解させない。
- 新しい2枚のバナーはクリックで対応する外部ページを新しいタブに開く。
- 既存のSORCERIAN Next 2020画像とNText紹介バナーは維持する。
- 468×60および300×250のサイズ違いは、外部サイト等で利用する素材として保持し、ページ内には重複掲載しない。

## 対象外

- 「シナリオ募集中」バナーの配置。
- 「募集中の企画」ページを含む他ページの変更。
- 既存の関連リンク一覧・ブログ記事リンクの削除や改変。
- バナー画像そのものの再デザイン。

## 互換性

- シナリオデータや既存ページのルート、リンク先は変更しない。
- サイト内の紹介画像・バナーは既存の `siteImageUrl` で配信する。Nextおよびブログのバナー画像は参考ページと同じ外部URLを使い、それぞれのリンク先を新しいタブで開く。
- 画像プレビューには既存の `ImagePreview` を使う。
- 画像のない場合でもページ本文の説明・操作には影響しない。

## 完了条件

- 「ソーサリアン Text とは？」ページに紹介イラストと歴史バナーが指定位置で表示される。
- 「関連リンク」ページに紹介バナーが指定位置で表示される。
- Nextおよびブログのバナーが対応する外部リンク付きで表示され、企画の時系列とNTextへの継承関係が説明される。
- 画像が画面幅に応じて適切に縮小され、画像プレビューで拡大できる。
- 代替テキストが設定され、既存のページ本文とリンクが維持される。
- 関連するテストと Player の型検査が通る。
