# Playground 編集中の Backspace によるページ離脱の防止

## 状態

実装済み（2026-11-18）。

## 目的

Playground でシナリオを編集中に、入力欄からフォーカスが外れた状態で Backspace キーを押すと、ブラウザーやその設定によっては前のページに戻ってしまう。誤操作で編集を中断しないようにする。

## 動作仕様

- Playground のシナリオ編集画面（編集用のダイアログを含む）で、文字を編集できる欄にフォーカスがない場合は、Backspace キーによるブラウザーの履歴移動を抑止する。画面の余白をクリックした直後や、ボタンまたは読み取り専用の欄にフォーカスがある場合も対象とする。
- 編集可能な入力欄や本文欄では、Backspace による文字の削除を従来どおり使える。
- ブラウザーの「戻る」「進む」ボタン、Backspace 以外のキー操作、試遊およびプレイヤーの操作は変更しない。

## 互換性

シナリオのデータ形式や保存方法は変更しない。既存データの移行やユーザーによる設定変更は不要。

## 完了条件

- 編集画面の余白やボタンなど、編集できない箇所で Backspace を押したときに、ブラウザーの既定動作が抑止されることを確認する。
- 編集可能な一行入力欄と本文欄では Backspace の既定動作が抑止されず、ブラウザー上で文字を削除できることを確認する。
- 試遊ではこの抑止が適用されず、ブラウザーの「戻る」ボタンは編集画面からも引き続き使えることを確認する。
