# 「新・消えた王さまの杖」v2移行仕様

## 状態

移行内容と経過シーン数表示の追加仕様は承認済み。実装済み。シナリオ検査はエラー・警告ともに0件。

## 目的と現状

最も古い作品の一つである「新・消えた王さまの杖」を、物語・分岐・難易度を保ったまま現行のプレイヤー操作に合わせる。原本は [`scenarios/scepter/scenario.json`](../../scenarios/scepter/scenario.json)、旧 XML は挙動と文章を照合する参照資料として扱い、旧形式から再変換して上書きしない。

事前確認では、シナリオは253シーン、敵61種、実績45件。移行前は `validateScenario`／`checkScenario` にエラー・警告がなく、シーンの `summary` と `groups` は未設定で、本文には旧「Battle Sheet」の案内が36シーンに残っていた。旧 XML と現行 JSON には複数の手動ステータス更新、5か所のチェックポイント再開、複数のバッドエンドがあるため、文章の一括置換やルート・効果の推測変更はしない。経過シーン数の表示は別仕様として承認を得て実装し、期限案内で使う。

## 対象範囲

- 全シーンに内容を識別できる短い `summary` を設定する。謎の答えや結末を不必要に明かさず、重複する見出しは区別する。
- 旧 XML に明示的な章区分はないため、本文とシーン番号のまとまりから `groups` を設定する。範囲は重複させず、全シーンをちょうど一つのグループに含める。グループには `bgm` と `rule` を設定せず、既存の BGM・戦闘ルールを変えない。
- 「Battle Sheet」など旧画面名の案内を、現行画面で実際にできる操作に合わせてシーンごとに修正する。戦闘は敵カードの「敵の攻撃」などを使い、特殊な判定・手動更新は必要な対象、値、順序を残す。
- 敵がいない状態でダイス判定が必要なシーンには、既存の敵なしダイス表示を使うため標準の6面ダイス2個（`dice: "6:2"`）を設定する。対象は3600、3610、3700、3710、3770、3790、5170、6060、6130、6140、6190、6230、6250、6270。
- Scene 2500 の5回のダイス判定と、出目ごとのダメージ／状態異常の処理は手動のまま残す。旧資料から各判定をどの敵カードに対応させるかを確定できないため、推測で自動化しない。
- 本文に内部欄名や旧画面名を出さず、プレイヤーに表示される名前と現行 UI の名称を使う。
- Scene 2350 では「記録」パネルの「経過シーン数」を基準値として冒険メモに記録するよう案内し、Scene 4000 では記録した値との差を確かめるよう案内する。50シーンの期限とエンジンのカウンター動作は変更しない。
- Scene 2350 の休息によるHP／MPの20回復と、七種類の「星の欠片」各2個の入手は「冒険者」パネルの「ステータスを編集」で手動適用する。HP／MPの上限も明記する。
- 固定値をシーン入場時に適用できるScene 1700（MP -1）、3820（HP／MP +10）、3850（HP -5、瓶の生命力 -2）、4520（MP +5）、6080（HP -5）、6200（HP +10、MP -1）、6210（HP／MP +20）、6290（HP -5）は `effects` に設定する。本文は適用結果を示す。
- Scene 2110 のMP増加は最大値を超えた分をHPに回せるため手動とする。Scene 3600、5170、6130、6140のダイス結果による変化、Scene 6160の回答・再訪回数によるMP回復、Scene 6220の選択・戦闘結果による変化も、各条件に応じた手動操作として案内する。Scene 6130の合計2は旧XMLでも2つの結果が重なるため、推測で解釈を変えない。
- Scene 3450 の `effects.free1: 20` は、旧 XML の説明から「瓶の生命力」と判断できる。`meta.labels.free1` にこの表示名を設定し、本文の「FREE欄」表記を整える。以後の戦闘ダメージに伴う瓶の生命力の更新は現行機能では自動化せず、手動操作として残す。
- 旧 XML と現行 JSON の効果を照合し、すでに設定済みの効果を重ねて追加しない。タイミング・回数・条件が明確で、既存効果がない固定値は自動化する。自動化で意味や難易度が変わる場合、または再現方法に確信が持てない場合は変更を止めて確認する。
- 既存の番号入力・チェックポイント再開、条件分岐、ランダム分岐、敵、報酬、実績、結末を維持する。チェックポイント再開用の5シーン（11550、13000、13290、15000、16400）と番号入力の許可値は変更しない。

## 対象外

- ゲームエンジンの経過シーン数の計算、戦闘 UI、シナリオ形式の機能追加。
- 瓶の生命力や独自のダイス判定など、現行 UI で直接表現できない処理の自動化。
- 物語の改稿、ルート追加、難易度・報酬・結末の調整、チェックポイント方式の変更。
- `meta.showSummary`、シーン・グループの BGM、戦闘ルールの変更。

## 完了条件と確認方法

- 変更後の `validateScenario`／`checkScenario` にエラー・警告がない。
- 253シーンすべてに短い `summary` があり、場面に沿うグループ範囲が重複せず全シーンを網羅する。
- Scene 2350・4000 の案内が「記録」パネルの同じ経過シーン数を参照する。
- 旧画面名の案内が残っていない。数値の自動効果と手動操作は旧 XML と照合され、対象・値・タイミング・条件が保たれている。
- 既存の条件・番号入力・チェックポイント・報酬・実績・エンディングへの遷移と、BGM・戦闘ルールに意図しない変更がない。
- 戦闘、繰り返し移動、手動ステータス更新、チェックポイント再開を含む代表的な経路を、固定ダイス等で確認する。実画面で確認できない項目は未実施として報告する。
