# BGM設定の改定計画

作成日：2026-11-10

本書は、シナリオのBGM設定を整理するための改定計画です。現時点では未実装です。
現在の形式は [シナリオ形式リファレンス](scenario-format.md) を参照してください。

## 1. 目的

- BGMの決定を移動履歴から切り離し、途中のシーンから試遊しても再生曲が決まる方式を追加する。
- 既存作品の設定を一括で書き換えず、作品単位で新方式へ移行できるようにする。
- PlayerとPlaygroundで曲の決定ルールを共通にする。
- 既存の暗黙ファイル名は維持し、新しい素材設定を必須にしない。

## 2. モードの切り替え

シナリオに明示的なモード項目は追加せず、グループのBGM設定から判定します。

| 条件 | モード |
| --- | --- |
| BGMを設定したグループが一つ以上ある | グループモード |
| BGMを設定したグループがない | 従来モード |

切り替えはシーン単位ではなく、シナリオ全体に適用します。
グループモードでは、BGM未設定のグループやグループ未所属のシーンも、新方式で判定します。

グループのBGM欄は、空欄なら未設定として保存します。
`@none` は明示的な無音の指定なので、モード切り替えの対象になります。

## 3. グループの設定

既存の `groups[]` に、省略可能な `bgm` を追加します。

```json
{
  "title": "森",
  "start": "100",
  "end": "199",
  "bgm": "@field01"
}
```

- 所属は既存と同じく、シーン番号が `start` 以上、`end` 以下かどうかで決めます。両端を含みます。
- 共通曲は `@field01` のように、固有曲は従来と同じファイル名の指定方法で記述します。
- `@none` は無音です。未設定とは区別します。
- BGMの有無にかかわらず、グループ同士の範囲重複は検査エラーにします。
- 例えば `100〜200` と `200〜300` は、シーン200の範囲が重なるためエラーです。
- 実在するシーンが重複部分になくても、範囲自体の重複を検査します。

既存の戦闘ルールの決定方法は変更しません。

## 4. 再生曲の決定

### 4.1 グループモードの通常シーン

以下の順で決定します。

1. 現在のシーンの `bgm`
2. 現在のシーンを含むグループの `bgm`
3. シナリオ全体の `meta.bgm.main`
4. 暗黙のファイル名 `main`

シーンの `bgm` が省略されている場合は、グループの `bgm` を参照します。
グループにもBGM指定がなければ、通常曲（優先順位3・4）を使います。
シーンの `bgm: ""` は「通常曲に戻す」指定として、グループのBGMを使わず通常曲（優先順位3・4）を使います。
直前の再生曲、セーブデータのBGM、試遊の開始BGMは、曲の決定に使いません。
グループを離れた場合も、以前の曲に戻すのではなく、上記の順で再判定します。
指定値が `@none` なら無音として決定し、後続の候補には進みません。

同じ曲のシーン間を移動しても、曲を先頭から再生し直す必要はありません。

### 4.2 従来モードの通常シーン

現行動作を維持します。

- シーンの `bgm` を省略した場合は、直前の曲を継続する。
- シーンの `bgm: ""` は通常曲に戻す。
- 通常曲は `meta.bgm.main`、未設定なら `main`。
- `@none` は無音。
- 試遊では従来の開始BGM指定を引き続き利用できる。

### 4.3 エンディング

従来モードは現状を維持し、グループモードだけシナリオ全体の終了曲設定を優先します。

#### グループモード

グループやシーンのBGM指定より、以下の終了曲を優先します。

| 終了種別 | 決定順 |
| --- | --- |
| `happy` / `good` | `meta.bgm.happy` → 暗黙のファイル名 `happy` |
| `bad` | `meta.bgm.bad` → 暗黙のファイル名 `bad` |

#### 従来モード

エンディングでもシーン個別のBGM指定があればそちらを優先します。
個別指定がなければ、現行どおりシナリオ全体の終了曲設定と既定曲の補完を使います。
シーンの `bgm: ""` は通常曲に戻す指定として維持します。

当初は両モードの終了曲ルール統一も検討しましたが、既存作品への影響を避けるため、互換性優先で確定しました。
暗黙ファイル名 `main` / `happy` / `bad` は維持します。

## 5. Playgroundの変更

- 定義タブのグループ一覧にBGM欄を追加する。
- 現在のBGMモードを表示する。
- 最初のグループBGM追加・最後の削除で作品全体のモードが切り替わることを通知する。
- グループモードでは、通常シーンの個別BGMがグループBGMより優先され、エンディングでは使われないことを表示する。空文字はグループ曲ではなく通常曲に戻す指定であることも案内する。
- 既存のシーン個別BGMは自動削除しない。
- グループモードの試遊では開始BGM指定を無効化し、グループ・シーン・通常曲・終了曲などの決定理由と現在の曲を表示する。
- グループのBGMを素材参照収集・不足確認に含める。暗黙ファイル名についても必要な素材を確認する。
- 無音の指定と素材不足を区別し、素材不足を黙って無音として扱わない。

編集中の一時的な重複では、シーン選択ボックスの表示を維持し、検査で重複箇所を示します。
現在の選択ボックスは、グループを開始番号順、各グループのシーンを番号順に表示し、未所属のシーンを末尾にまとめます。
重複があれば同じシーンが複数のグループに表示されます。検査導入のためにこの表示処理を作り直す必要はありません。

## 6. 既存システムへの影響

### 6.1 既存シナリオの調査結果

2026-11-10時点の、リポジトリ内の `scenarios/*/scenario.json` の集計結果です。

| 項目 | 件数 |
| --- | --- |
| 全作品 | 44 |
| グループを持つ作品 | 12 |
| グループ総数 | 43 |
| グループの範囲が重複する作品 | 0 |
| エンディングシーン | 358 |
| エンディングに個別BGM指定がある作品・シーン | 17作品・79シーン |
| 不採用の両モード統一案で曲名が変わる作品・シーン（参考） | 13作品・69シーン |

終了曲の比較は、現行の既定曲補完を踏まえた曲名の比較です。
実際の音源内容の同一性までは判定していません。
対象データが更新された場合は実装前に再集計します。

グループ重複禁止の導入だけなら、現存する作品の修正は不要です。
従来モードの終了曲は変更しません。既存作品をグループモードへ移行するときは、シーン個別の終了曲指定が無効になるため、演出変更を確認します。

### 6.2 変更箇所と規模

| 対象 | 変更内容 | 規模 |
| --- | --- | --- |
| `packages/schema` | グループBGMの型・正式検証・下書き検証との整合、範囲重複検査 | 小〜中 |
| `packages/core` | モード判定とBGM決定の集約 | 小〜中 |
| Playground | グループ編集、モード表示、試遊、素材参照管理 | 中 |
| Player | エンジンの決定結果に基づく再生、無音処理との整合 | 小 |
| CLI・音楽室向けデータ | グループBGMを使用曲集計に追加し、モードで無効な曲を除外 | 小 |
| 生成物・文書・テスト | JSON Schema再生成、仕様・ヘルプ・マニュアル・回帰テスト | 中 |

全体では中規模の改定です。再生機構全体の作り直し、依存追加、セーブ形式変更、既存作品の一括変換は基本的に不要です。
既存のBGM保存項目は互換性のために残し、グループモードでは曲の決定に使わない方針です。

新しい `groups[].bgm` を持つ作品は、更新前の厳密なスキーマでは読み込めません。
関連するパッケージとアプリを同じフェーズで更新します。

## 7. 実装と確認の手順

1. 本書の確定仕様に沿って、既存動作と新方式のテストケースを整理する。
2. スキーマ・範囲検査・エンジンの決定処理を実装する。
3. Playgroundの編集・試遊・素材管理と、Playerの再生を接続する。
4. 使用曲集計を更新する。旧シナリオの不要な再変換や、直接作成作品の上書きは避ける。
5. JSON Schemaをコマンドで再生成し、形式リファレンス・ヘルプ・関連マニュアル・開発文書を更新する。
6. 関連テスト、型検査、ビルドとブラウザーでの確認を行い、機能単位のPRにまとめる。

主な確認項目：

- グループBGMがない作品では、従来の通常進行・途中試遊・セーブ復元が変わらない。
- 一つでもグループBGMがあれば、作品全体がグループモードになる。
- グループの両端、未所属、BGM未設定グループで、期待する曲になる。
- 通常シーンでは、シーンBGMがグループBGMより優先され、シーンBGM省略時だけグループBGMを使う。
- シーンBGMが空文字ならグループBGMを使わず通常曲に戻し、シーン・グループともBGM未設定なら通常曲を使う。
- シーン指定の曲を次のシーンへ持ち越さず、移動先のシーンから再判定する。
- 明示的な無音、メイン曲・終了曲未設定時の暗黙ファイル名が正しく働く。
- 到達経路や保存済みBGM、試遊開始設定にかかわらず、グループモードの同じシーンで同じ曲になる。
- 通常移動・任意シーンからの試遊・やり直し・タブ再表示で、曲の決定が一致する。
- BGMの有無に関係なく、グループの範囲重複を検出する。
- 編集中の空欄や不正な範囲を、黙って別の曲に置き換えず検査・表示で扱う。
- 従来モードのエンディングではシーン指定を優先し、グループモードではグローバル終了曲を優先することを検証する。
- グループの固有曲・共通曲が素材管理と使用曲集計に反映される。
- 同じ曲での再生継続、曲変更、無音切替、自動再生制限の既存動作を維持する。
